# PROMPT ASSET INSTRUCTIONS

## OVERVIEW

This directory is a versioned prompt registry, not normal prose docs or Python
source. Runtime code loads `src/alex/prompts/<name>/active.txt` to choose a
`vNNN.md` template.

## STRUCTURE

```text
prompts/
|-- <prompt_name>/
|   |-- active.txt  # active version, e.g. v004
|   |-- v001.md     # immutable historical versions
|   `-- vNNN.md
`-- __init__.py
```

## WHERE TO LOOK

| Task | Location | Notes |
| --- | --- | --- |
| Load/substitute prompts | `src/alex/lib/prompt_templates.py` | Enforces placeholders and source-checkout writes. |
| Summary prompt stack | `chunk_summary*`, `final_summary`, `graph_guided_summary`, `merged_summary*` | Changes affect summary quality and eval comparability. |
| Judge/fact prompts | `fact_*`, `rubric_judge`, `claim_*` | Treat scoring prompts as eval contracts. |
| Prompt improvement flow | `prompt_critic`, `prompt_bundle_*` | Used by `alex improve-prompt(s)`. |
| Tests | `tests/test_prompt_templates.py`, `tests/test_prompt_improvement.py`, `tests/test_prompt_bundle_improvement.py` | Run focused tests after active-version changes. |

## CONVENTIONS

- Append prompt versions as `vNNN.md`; do not rewrite historical versions unless
  the user explicitly asks for history repair.
- `active.txt` contains only the active version string plus a trailing newline.
- Preserve the placeholder set unless the matching Python call site and tests
  are changed in the same task.
- Prompt prose is executable behavior. Small wording changes can change eval
  output; record why a new version exists when producing eval artifacts.
- Use `alex improve-prompt` or `alex improve-prompts` when following the
  automated improvement loop; `--promote` is required to rewrite `active.txt`.

## ANTI-PATTERNS

- Do not cite graph IDs in chunk summaries unless a task explicitly changes that
  contract.
- Do not invent claims, examples, source details, external facts, author bios,
  license framing, or section counts not supported by the supplied source text.
- Do not sharpen graph items into broader theses in repair or merged-summary
  prompts.
- Do not change judge prompts as part of improving a candidate summary prompt;
  that invalidates the comparison.
- Do not edit Python pipeline code, corpus files, scoring weights, model
  defaults, chunking, or graph settings when the task is prompt-only.

## COMMANDS

```bash
uv run pytest tests/test_prompt_templates.py tests/test_prompt_improvement.py -q
uv run alex eval-summary --prompt <prompt_name>=<version> --run-id <run_id>
uv run alex improve-prompt <prompt_name> --iterations 1
```

## NOTES

- `chunk_summary_with_graph` treats raw chunk text as the source of truth and
  the selected graph as an extraction aid.
- Final and repair prompts must preserve source faithfulness over elegance.
- Some newer prompt versions may be untracked or generated by current eval work;
  inspect `git status --short` before changing `active.txt`.
